# 📅 Calendário Dinâmico

Um projeto de calendário desenvolvido com **HTML, CSS e JavaScript**, criado como parte dos meus estudos de desenvolvimento web.

O projeto permite visualizar o calendário de forma dinâmica, navegar entre os meses e identificar o dia atual.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📌 Funcionalidades

* Exibição do mês e ano atual
* Navegação para o mês anterior
* Navegação para o próximo mês
* Identificação do dia atual
* Organização dos dias da semana
* Dias de outros meses exibidos de forma diferenciada
* Interface responsiva

## 🎯 Objetivo

O objetivo deste projeto é praticar:

* Manipulação do DOM com JavaScript
* Eventos de clique
* Manipulação de datas com `Date`
* Estruturas de repetição
* Grid Layout com CSS
* Organização de páginas com HTML
* Criação de interfaces interativas
